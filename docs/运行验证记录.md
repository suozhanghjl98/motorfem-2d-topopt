## 2. 端到端冒烟 `demo_smoke.py`

```bash
python -u tools/scripts/demo_smoke.py --start bars
```

结果：`T_flux = -0.846 N·m`，2 步 MMA 后 `-2.636 N·m`，设计变量 1207 个不变，
`=== 冒烟通过 ===`，总耗时 **204.9 s**（含建场）。

> `bars` 起点没做功角对齐，因此出现负值是预期现象。要看正转矩请走第 6 节的手绘起点。

## 6. 从手绘起点跑完一次优化

```bash
python -u tools/scripts/run_auto_schedule.py --motor 6s4p \
  --x0-npz examples/hand_design.npz --x0-key x0 \
  --filter-radius-mm 0.9 --max-density 0.85 \
  --stages "S0:T=40,R=80" --max-eval-per-stage 10 --n-min 10 \
  --max-budget-shrinks 0 --max-relax-back 0 --wall-seconds 1800 \
  --out tools/_out/demo/hand_run
```

结果（10 步，**580 s**）：

| 指标 | 手绘起点（第 1 步） | 第 10 步（最优） | 验证集独立复算（6 点） |
|---|---|---|---|
| T̄ (N·m) | 43.645 | **48.757** | 48.555 |
| 脉振 R | 24.81 | 29.90 | 19.92 |
| σ (MPa) | 305.99 | 272.78 | 272.78 |
| ρ̄ | 0.873 | 0.815 | 0.8148 |

判据：`--- S0: advance (evals=10) feasible=True` → **`COMPLETE tag=run evals=10 580s`**。
产物：`hand_run.log`、`hand_run_summary.json`（`n_evals=10`、`pool=11`）、
`hand_run_stage_S0.npz`（`x_best (1207,)`、`x_calls (11, 1207)`）。

解读：手绘起点本身给出 43.6 N·m 的正转矩，10 步内优化把平均转矩抬到 48.76 N·m（+11.7%），
同时把最大 von Mises 应力从 306 MPa 压到 273 MPa；验证集独立复算 48.555 N·m，
与训练集差 0.4%，说明抬升来自结构本身。

### 本轮未覆盖的一项

全新机器上的 `pip install -r requirements.txt` 没有实测（建 venv 那步被取消）。
首次安装完成后先跑 `python verify_env.py`：它会把缺依赖、缺 numba、缺 golden 文件、
后端不可用这几类问题一次性报出来，比直接跑优化更容易定位。
